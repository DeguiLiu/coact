# isp_pipeline_demo 运行日志实录

> 采集方式：`timeout 60s ./build/examples/isp_pipeline_demo > docs/isp_pipeline_demo_run_log.txt 2>&1`。
> 本次采集为修复后 pthread 模式示例，退出码为 0，66 项断言全部通过。
> 以下说明行以中文补充日志阅读上下文；其余内容为程序原始输出。

## 日志阅读指南

### 一、输出类型

| 输出 | 含义 |
|---|---|
| `[worker] ...` | 非 AO worker 的启动、排空和退出，反映停机时序与执行统计。 |
| `[orch] ...`、`[session] ...`、`[hsm] ...` | 编排器、会话状态机和各 AO 的可读轨迹。 |
| `[时间戳] e=... s=... a0..a3=...` | 结构化诊断日志；参数保持十六进制，便于机器解析和与可读日志交叉核对。 |
| `[PASS] ...` | 运行期验收断言；末行 `RESULT: ALL PASS` 是进程级成功标志。 |

### 二、结构化事件码

| 事件码 | 含义 |
|---|---|
| `e=1..4` | Preview Start 的 Boot、Phase1、Phase3、Phase4 阶段。 |
| `e=7` | video PIC/TEMP 命令，`s=0` 为 PIC，`s=1` 为 TEMP。 |
| `e=10` | MIPI 首帧到达 sink。 |
| `e=12` | HSM 状态迁移；`a0` 为 AO 编号，`a1` 为源状态，`a2` 为信号，`a3` 为目标状态。 |
| `e=13` | X1/X2 原子重配阶段，包括拒绝、回滚和提交。 |
| `e=14` | worker 执行/拒绝统计。 |
| `e=15` | 会话状态迁移：`0=BOOT`、`1=INIT`、`2=RUNNING`、`3=RECFG_TXN`、`4=DEINIT`、`5=STOPPED`。 |

### 三、本次重点验收

1. `video_fsm PIC --(7)--> REJECTED`：验证 IDLE 态非法 START 被保护弧拒绝。
2. `wrape` 的 T37 阶段输出 3 个 `ERR+EOF` 截断帧，随后 X2 几何下完整帧恢复。
3. 末尾 worker 统计应保持 `rejected=0`，事件池 `pool.used=0` 表示无泄漏。
4. 本次修复针对 coro 后端的当前协程身份绑定；pthread 日志用于确认默认模式零回归。
